# 接待ゴルフ「入る理由」データの書き方（全員共通）

## ゲーム
ブラウザゲーム「接待ゴルフ」。最終ホールのグリーン。上司（部長）のパットはカップのふちで止まった。
プレイヤーは上司を勝たせないといけないのに、どう打っても（どのクラブで・どの向きに・どの強さで打っても）
「何かが起きて」ボールが必ずカップに入ってしまう。その「入る理由」を 1 行ずつ書く。
笑いの方向：「なんでやねん」とイラッとする・しょうもない・シュール。接待ゴルフ・会社・ゴルフ場らしさ、動物、乗り物、超常現象など幅広く。
登場人物は架空の一般人・職業・動物・物だけ（実在の人物・有名キャラ・商品名・企業名は禁止）。下品・差別・暴力表現は禁止。
ネタばれ禁止：「クラブを折る」「上司にボールを投げる」に触れる理由は書かない。

## 形式
JSON 配列のファイル（JSON.parse で読めること）。1 要素 = 1 理由 = 次の 9 個の配列：
["id", "type", "cats", actor, params, "ja", "en", "zh", "ko"]

- id：英小文字・数字・_ のみ、ファイル内で重複なし。指定のプレフィックスで始める（例 "a_caddie_kick"）
- type：下の 11 種類のどれか
- cats：出る場面の文字を並べた文字列（例 "pn"）。type ごとに使ってよい文字が決まっている（下）
- actor：登場するもの（下の語彙だけ使う。語彙にないものは文章で表現し、見た目は近いものを選ぶ）
- params：type ごとの数値（下）
- 文章 4 つ（日本語・英語・繁体字中国語・韓国語）："理由|吹き出し" の形。必ず「|」が 1 つだけ
  - 理由：何が起きてカップに入ったかを 1 文で（日本語は 30 文字以内、「〜された」「〜した」などの過去形）
  - 吹き出し：登場したものが言う一言（日本語は 12 文字以内）。しゃべらないものは（……）や効果音
  - 英語・中国語（繁體）・韓国語は自然な意訳（ゲームらしく短く）

### 出る場面 cats の文字
p = カップの3m以内に止まった / n = 15m以内 / m = 15〜60m / f = 60〜150m / x = 150m以上の遠く /
w = 池に落ちた / h = 高く上がった球（ウェッジ） / b = カップと反対の後ろ向きに打った

### type と params と cats と actor
| type | 何が起きる | params | cats に使える文字 | actor |
|---|---|---|---|---|
| kick | 近くにいた人・動物が歩いてきて、転がして／蹴って入れる | {"spd": 歩く速さ 1〜6} | p n | 人 か 地面の動物 |
| carry | 人・動物・乗り物がボールの所まで行き、拾って運び、カップに落とす | {"spd": 速さ 1〜40, "mv": "walk"/"run"/"fly"/"drive"/"crawl"/"hop"} | n m f x b | 人・動物・乗り物 |
| hit | ボールのそばに現れた人などが、打ち返して・蹴り返して高い弧でカップに入れる | {"h": 弧の高さ 0.5〜3} | n m f x b | 人（道具を持つ）・動物 |
| bounce | 飛んでいる（転がっている）途中で何かに当たり、跳ね返ってカップに入る | {"f": 飛んでいる途中のどこで当たるか 0.3〜0.9, "h": 跳ねた弧の高さ 0.5〜3} | p n m f x h b | 物・動物・人・乗り物 |
| air | 空を飛ぶもの（鳥・ヘリなど）が空中や地面のボールをつかみ、カップの上まで運んで落とす | {"spd": 飛ぶ速さ 5〜60} | n m f x h | 鳥・空の乗り物・物 |
| erupt | 地面から何か（モグラ・噴水・バネなど）が出てきて、ボールをはね上げてカップに入れる | {"delay": 出てくるまでの秒 0.3〜2} | p n m f | 地面の動物・物 |
| roll | 風・傾き・地震・磁石などで、ボールが不自然に転がってカップに入る | {"spd": 転がる速さ 0.5〜6, "curve": 曲がり -1〜1} | p n m | 物（なければ {"o":"none"}） |
| cupmove | カップのほうがボールの所へ来る（グリーンキーパーが掘り直す・カップが歩くなど） | {"spd": 0.5〜8} | p n m | 人・地面の動物・{"o":"none"} |
| boss | 上司（部長）本人がうっかり入れてしまう（つまずく・頭に当たる・素振り・くしゃみ・靴など） | {"mode": "trip"/"head"/"swing"/"sneeze"/"shoe"} | p n m | {}（上司が出る） |
| water | 池に落ちたボールを、池から出てきたものが投げ返して／はね上げてカップに入れる | {"delay": 0.5〜2.5} | w | 水の動物・人・{"v":"boat"} |
| warp | 超常現象（時間が戻る・ワープ・地球一周など）で消えて、カップの真上から落ちてくる | {"delay": 0.5〜6} | p n m f x h b w のどれでも | {"o":"portal"}/{"o":"whirl"}/{"o":"none"} |

### actor の語彙（これ以外の値は使わない）
- 人：{"p": {"c": "#rrggbb"（服の色）, "hat": "cap"/"helmet"/"straw"/"chef"/"top"/"band"/"bun"/"none", "prop": "club"/"bat"/"racket"/"broom"/"net"/"rake"/"umbrella"/"pan"/"stick"/"flag"/"fan"/"none", "s": 大きさ 0.5〜1.8（省略で1）, "w": 太さ 0.8〜1.8（省略で1）}}
- 動物：{"a": "dog"/"cat"/"monkey"/"deer"/"boar"/"bear"/"kangaroo"/"cow"/"horse"/"rabbit"/"squirrel"/"tanuki"/"fox"/"goat"/"capybara"/"crow"/"pigeon"/"eagle"/"duck"/"seagull"/"owl"/"pelican"/"penguin"/"ostrich"/"mole"/"turtle"/"frog"/"snake"/"carp"/"fish", "c": "#rrggbb"（省略可）, "s": 大きさ（省略可）}
- 乗り物：{"v": "cart"/"mower"/"drone"/"heli"/"balloon"/"ufo"/"plane"/"truck"/"bike"/"rocket"/"robot"/"boat"/"blimp", "c": "#rrggbb"（省略可）}
- 物：{"o": "tree"/"sign"/"rock"/"wall"/"spring"/"tramp"/"pole"/"statue"/"fan"/"magnet"/"portal"/"geyser"/"sprinkler"/"vending"/"mirror"/"cone"/"bucket"/"pipe"/"hand"/"whirl"/"none", "c": "#rrggbb"（省略可）}

## 例

["b_crow_carry","carry","mfx",{"a":"crow"},{"spd":14,"mv":"fly"},"カラスにくわえて運ばれ、カップに落とされた|カァー","A crow carried it off and dropped it in the cup|Caw!","被烏鴉叼走，丟進了洞裡|嘎——","까마귀가 물고 가서 홀컵에 떨어뜨렸다|까악"]

## 仕上げ
- 書き終えたら node で JSON.parse し、件数・id の重複・type ごとの件数・cats の文字・「|」の数・日本語の長さを自分で確かめて直す
- 同じネタのくり返しは避ける（同じ人・動物でも状況を変える）
